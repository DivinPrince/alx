# API Documentation

## Overview

Alx is a Next.js-based AI-powered competitive programming solution generator. It provides a chat interface where users can request solutions to competitive programming problems, and the AI generates complete, compilable code solutions with analysis and verification.

## Server Actions

### `generateCode(prompt: string): Promise<string>`

**Location**: `app/actions.ts`

Generates competitive programming solutions using Google's Gemini AI model.

**Parameters:**
- `prompt` (string): User's problem description or request

**Returns:**
- `Promise<string>`: AI-generated solution with analysis

**Example Usage:**
```typescript
import { generateCode } from './actions'

const solution = await generateCode("Solve the two-sum problem")
```

**Features:**
- Uses Google Gemini 1.5 Flash model
- Includes comprehensive system prompt for competitive programming
- Generates complete, compilable solutions
- Provides algorithmic analysis and verification
- Handles memory constraints (512MB limit)
- Includes test case generation

**System Prompt Capabilities:**
- Checker analysis using testlib.h framework
- Solution generation protocol
- Code generation rules
- Output verification steps
- Testing methodology
- Error prevention guidelines

## React Components

### `ChatComponent` (Default Export)

**Location**: `app/page.tsx`

Main chat interface component that manages conversation state and user interactions.

**Props:** None (default export component)

**State:**
- `messages`: Array of conversation messages
- `input`: Current input text
- `isPending`: Loading state for AI responses

**Features:**
- Real-time chat interface
- Message history management
- Auto-scrolling to latest messages
- Error handling for AI responses
- Form submission with server actions

**Example Usage:**
```jsx
import ChatComponent from './page'

export default function App() {
  return <ChatComponent />
}
```

### `MessageBubble`

**Location**: `app/page.tsx` (lines 14-77)

Renders individual chat messages with markdown support and code copying functionality.

**Props:**
```typescript
interface MessageBubbleProps {
  message: Message
}
```

**Features:**
- Markdown rendering with ReactMarkdown
- Syntax highlighting for code blocks
- Copy-to-clipboard functionality for code
- Visual feedback for copy operations
- Responsive design with role-based styling

**Example Usage:**
```jsx
const message = { role: 'assistant', content: '```python\nprint("Hello")\n```' }
<MessageBubble message={message} />
```

### `ChatInput`

**Location**: `app/page.tsx` (lines 79-102)

Input form component for sending messages to the AI.

**Props:**
```typescript
interface ChatInputProps {
  formAction: (formData: FormData) => void
  isPending: boolean
  input: string
  setInput: (value: string) => void
}
```

**Features:**
- Textarea for multi-line input
- Submit button with loading states
- Disabled state during AI processing
- Responsive design with Tailwind CSS

**Example Usage:**
```jsx
<ChatInput
  formAction={formAction}
  isPending={false}
  input={inputValue}
  setInput={setInputValue}
/>
```

**Location**: `app/page.tsx` (lines 9-12)

## Development Guide

### Getting Started

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Set Up Environment:**
   - Configure Google AI API credentials
   - Set up environment variables for AI SDK

3. **Run Development Server:**
   ```bash
   npm run dev
   ```

4. **Access Application:**
   - Open http://localhost:3000

### Key Dependencies

- **Next.js 15.0.1**: React framework
- **React 18.3.1**: UI library
- **@ai-sdk/google**: Google AI integration
- **react-markdown**: Markdown rendering
- **react-icons**: Icon components
- **Tailwind CSS**: Styling framework

### Build and Deploy

```bash
# Build for production
npm run build

# Start production server
npm run start

# Lint code
npm run lint
```
